🔒 Encryption key

On your other devices (PC, another phone), paste the same key or open the saved key file. All devices must use the same key.
The key is created on this device and stays here. It only leaves when you copy or save it. If you lose the key, the data on GitHub can’t be recovered. Keep the key file somewhere safe, such as a password manager.

GitHub account

On github.com go to Settings › Developer settings › Fine-grained tokens › Generate new token. Under Repository access choose Only select repositories and pick your data repository and app repository. Under Permissions set Contents → Read and write. Give it an expiry date. The token is stored only on this device.

📋 Asset list (models)

Upload your asset database (CSV with Equipment ID, Serial, Vendor, Department, Model, Description). It is stored encrypted in your private GitHub repository, so every device can use it. When you type or scan an Asset ID the model shows under it, and the sentences you often write for that model are offered under Fault and Resolution.

Fill AGL

Press → AGL on a job in the Dashboard. It copies the job and opens a helper window with each value in Agility’s order (click to copy, or load all into Win+V). With the Fill AGL extension installed in Edge, just click ⚡ Fill AGL on the Agility form instead.
Log Dashboard jobs into Agility by themselves: opens the Agility menu, clicks the button below, runs Fill AGL, presses Complete after the countdown, and saves the WO#. Be logged in to Agility. If Edge blocks the Agility tab, allow pop-ups for Repair Logger. Agility opens each new request in a pop-up, so also allow pop-ups for https://agility (Edge: edge://settings/content/popups › Allowed › Add).
Kept encrypted in your private GitHub repository, not on this public page. Uploading and downloading need this device’s GitHub token and encryption key.

Fill EAM (ServiceNow)

Set this up on the PC you use for ServiceNow (no Tampermonkey needed; Tampermonkey is only for Agility). After a job has its AGL WO#, press → EAM on the Dashboard, then click the ⚡ Fill EAM bookmark in ServiceNow. It works from any ServiceNow page and shows what it will create; nothing happens until you press Create Work Order. It uses your ServiceNow login in Edge (the same method as Service Report Helper); no password is stored. The new number comes back and the job is marked EAM done. Fill the form instead is there as a backup.
⚡ Fill EAM
Like Service Report Helper’s EAM link. Press Make the bookmark (it is built from the script in your private repository), then drag ⚡ Fill EAM onto the bookmarks bar (Ctrl+Shift+B shows it). In ServiceNow, click the bookmark. If → EAM opened the ServiceNow tab, the job and the new number pass directly between the two tabs.
Open a new Work Order in ServiceNow, copy the address bar and paste it here. → EAM then opens it for you.
Field names as shown on the form. Several names separated by commas: the first one found is used.

🔐 Back up this device

Saves your settings, GitHub token and encryption key in one file, locked with a password you choose. If an update, the browser or iPhone ever clears them (or on a new device), use Restore from setup file and type the password. Keep the file somewhere safe (e.g. email it to yourself or a password manager).

Other devices

Opens this app on another device with the same settings and tags. The GitHub token and encryption key are not included; add them on that device.
