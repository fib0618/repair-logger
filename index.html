🔒 Encryption key

On your other devices (PC, another phone), paste the same key or open the saved key file. All devices must use the same key.
The key is created on this device and stays here. It only leaves when you copy or save it. If you lose the key, the data on GitHub can’t be recovered. Keep the key file somewhere safe, such as a password manager.

GitHub account

On github.com go to Settings › Developer settings › Fine-grained tokens › Generate new token. Under Repository access choose Only select repositories and pick your data repository and app repository. Under Permissions set Contents → Read and write. Give it an expiry date. The token is stored only on this device.

Update app

Version on this device:
Choose the new index.html you were given. It replaces the app on GitHub and GitHub Pages publishes it in about a minute. Then tap Reload app on each device. Uses the token from GitHub account.

Fill AGL

Press → AGL on a job in the Dashboard. It copies the job and opens a helper window with each value in Agility’s order (click to copy, or load all into Win+V). With the Fill AGL extension installed in Edge, just click ⚡ Fill AGL on the Agility form instead.
The extension’s code is kept encrypted in your private GitHub repository, not on this public page. Downloading it needs this device’s GitHub token and encryption key (see GitHub account and Encryption key, with Save location set to GitHub).
If Developer mode is greyed out in edge://extensions: install Tampermonkey from the Edge Add-ons store (if your PC allows it), then in edge://extensions › Tampermonkey › Details turn on Allow user scripts if you see it. Open the Tampermonkey icon › Create a new script, delete what’s there, paste the contents of the downloaded fill-agl-tampermonkey.txt (double-click opens it in Notepad) and press Ctrl+S. The ⚡ Fill AGL button then appears on Agility pages.
To install the download:
  1. Unzip it to a folder you’ll keep, e.g. Documents\Fill AGL.
  2. In Edge go to edge://extensions and turn on Developer mode (bottom-left).
  3. Click Load unpacked and choose that folder.
  4. Open an Agility form and look for the blue ⚡ Fill AGL button at the bottom-right.
When you get a new fill-agl-core.js, upload it here, download the extension again, unzip over the same folder and click ↻ on the extension in edge://extensions.
